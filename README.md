# Computer-Use Automation System

A focused implementation of an LLM-driven discovery loop that compiles a successful UI run into a typed capability artifact and replays it deterministically without an LLM in the decision path.

> Status: active implementation. Setup and exact demonstration commands will be completed with the end-to-end slice.

## Security

- Keep API credentials in `.env.local`; the file is ignored by Git.
- The demo uses synthetic member data only.
- Run artifacts and logs redact declared input values.
